## 🚀 프로젝트

### 🚗 [raspberrypi-qnx-cluster](https://github.com/jeongsemin/raspberrypi-qnx-cluster)

`상태: 진행 중 (개인 학습용)`

QNX 8.0과 Qt 6.8.5로 만든 **차량 계기판**을 라즈베리 파이 4 또는 QEMU VM에 띄우고, PC의 테스트 콘솔에서 가상 ECU 신호와 진단(DTC, UDS)을 시험하는 프로젝트. 업무에서 다루는 차량 통신·진단 개념을 직접 구현해 보며 익히고 있습니다.

- 게이트웨이가 UDP로 받은 CAN 프레임을 검사하고 E2E 보호(CRC, 카운터)를 붙여 계기판에 전달, 값이 이상하면 계기판이 안전 화면을 표시
- DTC를 저장하고 UDS 서비스(10, 3E, 22, 19, 14, 27, 11)에 응답하는 진단 서버
- PC 테스트 콘솔(가상 ECU, 결함 주입, 주행 시나리오, 기록·재생)과 단위·종단·교차 확인 시험, Windows 런처(exe)
- `C` · `C++` · `Qt Quick(QML)` · `QNX` · `Python`

### 🏥 [KONCI](https://github.com/jeongsemin/konci)

`상태: 배포 준비 중 (konci.kr)`

한국을 찾는 외국인을 위한 **영수증 인증 기반 병원·피부과 후기 서비스** (영어, 일본어, 중국어, 한국어). 이전 이름은 MediMate입니다.

- 영수증 사진을 OCR로 검증해 병원명, 날짜, 금액이 맞으면 자동 승인하고, 아니면 관리자 검수 대기열로 보내는 흐름
- 사진 SHA-256 중복 방지, 영수증 1장당 후기 1개, DB의 RLS로 승인된 영수증 없이는 후기 작성 불가
- 건강보험심사평가원 공공데이터로 병원·의원 약 4만 곳을 적재해 검색·비교하고, 폐업·이전한 병원은 후기 작성을 막음
- 신고, 정보 수정 요청, 건의사항 등 관리자 화면과 예약 안내(한국어 문구 카드)
- 구글·이메일 링크 로그인, 만 14세 확인, 후기 없는 영수증 사진 30일 뒤 삭제, 보안 헤더, 단위 테스트 178개
- `Next.js` · `Supabase(Auth, Postgres + RLS, Storage)` · `Naver CLOVA OCR` · `Tailwind CSS`
